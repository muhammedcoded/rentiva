# Nigeria location import

Rentiva imports the hierarchy from the community-maintained Nigeria Locations Dataset (2026):

https://github.com/ayoolaowoilu/Nigeria-Locations-Dataset-2026-API

The dataset describes 37 administrative entries (36 states plus FCT), 774 LGAs and local towns/areas. It is not an authoritative register of every informal street, estate or neighbourhood. The location selector supports manual area entry as a fallback. Review the source repository's licence and attribution requirements before redistributing its data.
